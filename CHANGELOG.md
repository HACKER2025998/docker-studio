# Historique

## 2.0.0-alpha.1 — livraison de développement, 25–26 octobre 2026

Première implémentation DockForge issue des deux spécifications v2 : atelier desktop Rust/Tauri/React, catalogue de 35 services, diagnostic local, création guidée, volumes, réseau, GPU, accès chiffrés et constructeur BuildKit.

Cette livraison ajoute aussi la liaison à des bases déjà gérées, la sauvegarde portable Argon2id/AES-GCM, le suivi volontaire d’historiques et un partage LAN HTTPS à droits révocables. Le README, les commentaires pédagogiques, les sources client et les rapports de recette accompagnent le code.

La matrice `docs/EXIGENCES.md` décrit les variantes et limites. Le statut alpha distingue une application exécutable d’une certification de toutes les plateformes et de tous les modèles du catalogue.
